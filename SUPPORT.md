# Support

Where to take what. This is a side project maintained by one person, so please pick the right door:
it gets your question to the right place, and lets everyone else find the answer later.

| I want to...                                     | Go to                                                                                                                                                           |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Learn how something works                        | The [documentation site](https://nguyenan97.github.io/angular-saas-kit/docs/)                                                                                   |
| Understand why it is built this way              | The [architecture decision records](docs/adr/README.md)                                                                                                         |
| Ask a usage question, or float an idea           | [Discussions](https://github.com/nguyenan97/angular-saas-kit/discussions)                                                                                       |
| Report a bug                                     | The [bug report form](https://github.com/nguyenan97/angular-saas-kit/issues/new?template=bug_report.yml). A minimal reproduction decides whether it gets fixed. |
| Request a component                              | The [component request form](https://github.com/nguyenan97/angular-saas-kit/issues/new?template=component_request.yml)                                          |
| Report an accessibility problem                  | The [accessibility form](https://github.com/nguyenan97/angular-saas-kit/issues/new?template=accessibility.yml)                                                  |
| Report a security vulnerability                  | **Privately**, as described in the [security policy](SECURITY.md). Do not open a public issue.                                                                  |
| Report behaviour that breaks the code of conduct | See the [code of conduct](CODE_OF_CONDUCT.md)                                                                                                                   |
| Contribute a change                              | [CONTRIBUTING.md](CONTRIBUTING.md)                                                                                                                              |
| Support the project                              | [Sponsor](https://github.com/sponsors/nguyenan97)                                                                                                               |

## What to expect

Security reports are acknowledged within 72 hours (see the [security policy](SECURITY.md)). For everything
else there is no service level: issues and discussions are read, and answered when time allows. A question
that the docs answer may be pointed at the docs. Commercial support is not offered.
